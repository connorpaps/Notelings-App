## Issues found and fixed during this pass

1. **Local `/demo` workspace was broken (500).** `.env.local` still used the legacy `NEXT_PUBLIC_SUPABASE_*`/`SUPABASE_SERVICE_ROLE_KEY` names and had no unified `DEMO_*`/`NEXT_PUBLIC_DEMO_*` set, so `getSupabaseConfig('demo')` threw `Missing DEMO_SUPABASE_URL`.
   - Fix: derived the demo URL/anon/service-role values from `.env.demo.local` and added them to `.env.local` under the unified names (value-copied, never printed). Private root was left on the supported legacy fallback.
2. **Local demo sign-in failed even after env migration.** `.env.local`'s `NOTELINGS_DEMO_PASSWORD` was stale; it differed from `.env.demo.local` and returned `invalid_credentials` from the demo Supabase project.
   - Fix: verified the valid password against the demo Supabase token endpoint, then copied it into `.env.local`.
3. **E2E webServer could not bind :3000.** The Playwright `webServer` did not pin `PORT`, and the ambient shell exports `PORT=0`, so `next dev` bound a random port while the health check waited on :3000 → 120s timeout.
   - Fix: pinned `PORT: '3000'` in `playwright.config.ts` `webServer.env`.
4. **`.freebuff/` was untracked and not ignored.** Added to `.gitignore`.
5. **`next-env.d.ts` carried a dev-mode generated diff.** Restored to the committed form (it is a generated file that must not be committed with the `.next/dev/types` paths).
