## Historical material

Archived specifications, audits, milestone plans, old deployment checklists, and reference screenshots remain here so the engineering history is not lost. They may describe an earlier dark/Skybridge shell, unauthenticated MVP, separate demo deployment, OBJ office, or pre-Graph roadmap. Those details are historical and do not override the current files above.

The original OBJ office implementation and its binary assets are separate under [`../../archive/legacy-office/`](../../archive/legacy-office/README.md).
